# Document Request Portal

ระบบขอเอกสารออนไลน์สำหรับงานทะเบียนของโรงเรียนและมหาวิทยาลัย
**ยื่นคำร้อง → ตรวจสอบข้อมูล → ติดตามสถานะ → แจ้งเมื่อเอกสารพร้อมรับ**

ไม่ต้องใช้ Node.js หรือขั้นตอน build ตัวเว็บเป็น HTML + JavaScript (ES modules) ล้วน เชื่อมต่อฐานข้อมูลผ่าน Supabase

## ฟีเจอร์

**นักเรียน/นักศึกษา** (ไม่ต้องสมัครสมาชิก)
- เลือกประเภทเอกสาร พร้อมดูค่าธรรมเนียม ระยะเวลา และเอกสารที่ต้องแนบ
- กรอกข้อมูลและแนบไฟล์ (PDF/JPG/PNG ไม่เกิน 5 MB, สูงสุด 5 ไฟล์)
- รับรหัสติดตาม และตรวจสถานะได้ด้วยรหัสติดตามคู่กับรหัสนักเรียน
- สลับภาษาไทย/อังกฤษได้ทันที

**เจ้าหน้าที่ทะเบียน** (ล็อกอิน)
- ดู กรอง และค้นหาคำร้อง
- เปิดไฟล์แนบ เปลี่ยนสถานะ และฝากข้อความถึงผู้ยื่น
- ประวัติการเปลี่ยนสถานะบันทึกอัตโนมัติ
- สมัครบัญชีใหม่ได้เองที่หน้า `#/register` โดยต้องใส่รหัสลงทะเบียนที่ผู้ดูแลระบบตั้งไว้

## เทคโนโลยี

| ด้าน | สิ่งที่ใช้ |
|---|---|
| ภาษา | HTML, CSS, JavaScript (ES modules), SQL (PostgreSQL / PL/pgSQL) |
| Framework | ไม่มี (vanilla JavaScript + hash router) |
| ไลบรารี | `@supabase/supabase-js` v2 (CDN), ฟอนต์ Sarabun (Google Fonts) |
| Backend | Supabase: PostgreSQL, Auth, Storage, Row Level Security, RPC |
| Hosting | Vercel (static) |
| Source control | GitHub |

## โครงสร้างโปรเจกต์

```
index.html              โครงหน้าเว็บ
css/styles.css          สไตล์ทั้งหมด
js/config.js            ค่าเชื่อมต่อ Supabase (URL + anon key)
js/app.js               router และแถบเมนู/ปุ่มสลับภาษา
js/i18n.js              ข้อความภาษาไทย/อังกฤษทั้งหมด
js/lib/supabase.js      Supabase client
js/lib/utils.js         ฟังก์ชันและค่าคงที่ที่ใช้ร่วมกัน
js/pages/home.js        #/          หน้าแรก
js/pages/request.js     #/request   ยื่นคำร้อง
js/pages/track.js       #/track     ติดตามสถานะ
js/pages/admin.js       #/admin     หลังบ้านเจ้าหน้าที่
js/pages/register.js    #/register  สมัครเจ้าหน้าที่ (ต้องมีรหัสลงทะเบียน)
supabase/schema.sql     ตาราง นโยบาย RLS ฟังก์ชัน RPC storage และข้อมูลตัวอย่าง
supabase/add_staff_registration.sql  แพตช์ระบบสมัครเจ้าหน้าที่ (สำหรับฐานข้อมูลที่รัน schema.sql ไปแล้ว)
vercel.json             HTTP security headers
```

## โครงสร้างข้อมูล

| ตาราง | หน้าที่ |
|---|---|
| `request_types` | ประเภทเอกสาร: ชื่อ คำอธิบาย ค่าธรรมเนียม จำนวนวันดำเนินการ เอกสารที่ต้องแนบ (มีคอลัมน์ `_th` สำหรับภาษาไทย) |
| `requests` | คำร้อง: ข้อมูลผู้ยื่น รหัสติดตาม สถานะ ข้อความจากเจ้าหน้าที่ |
| `attachments` | ข้อมูลไฟล์แนบ (ตัวไฟล์อยู่ใน Supabase Storage) |
| `status_history` | ประวัติการเปลี่ยนสถานะ (เขียนโดย database trigger) |
| `staff` | ผู้ใช้ที่ได้รับสิทธิ์เป็นเจ้าหน้าที่ |
| `staff_settings` | ค่าตั้งค่าลับ เช่น รหัสลงทะเบียนเจ้าหน้าที่ (เปิดอ่านได้จาก SQL Editor เท่านั้น) |
| `staff_register_attempts` | จำนวนครั้งที่กรอกรหัสลงทะเบียนผิดของแต่ละผู้ใช้ (ผิดครบ 5 ครั้งจะถูกล็อก) |

ฟังก์ชัน RPC: `submit_request`, `add_attachment`, `track_request` (ผู้ยื่นคำร้อง) และ `register_staff` (ผู้ใช้ที่ล็อกอินแล้ว)

### ค่าสถานะ

`submitted` → `reviewing` → `need_more_info` → `approved` → `processing` → `ready` → `completed` และ `rejected`, `cancelled`

## ข้อกำหนด (Requirements)

### Functional

| รหัส | ข้อกำหนด |
|---|---|
| FR-1 | เลือกประเภทเอกสารที่เปิดให้ขอ พร้อมแสดงค่าธรรมเนียม ระยะเวลา และเอกสารที่ต้องแนบ |
| FR-2 | กรอกชื่อ รหัสนักเรียน อีเมล เบอร์โทร วัตถุประสงค์ จำนวนฉบับ (1–20) และวิธีรับ (รับเอง/ไปรษณีย์) |
| FR-3 | แนบไฟล์ได้สูงสุด 5 ไฟล์ ชนิด PDF/JPG/PNG ไม่เกิน 5 MB ต่อไฟล์ |
| FR-4 | ได้รับรหัสติดตาม (`DR-XXXXXXXX`) หลังยื่นสำเร็จ |
| FR-5 | ดูสถานะ ข้อความจากเจ้าหน้าที่ และประวัติสถานะ โดยกรอกรหัสติดตามและรหัสนักเรียนให้ตรงกัน |
| FR-6 | เจ้าหน้าที่ล็อกอินและเห็นคำร้องล่าสุด 200 รายการ |
| FR-7 | กรองตามสถานะ และค้นหาด้วยรหัสติดตาม รหัสนักเรียน หรือชื่อ |
| FR-8 | เปิดดูรายละเอียดและดาวน์โหลดไฟล์แนบ |
| FR-9 | เปลี่ยนสถานะพร้อมฝากข้อความที่แสดงให้ผู้ยื่นเห็น |
| FR-10 | บันทึกประวัติสถานะอัตโนมัติทุกครั้งที่เปลี่ยนสถานะ |
| FR-11 | สมัครบัญชีเจ้าหน้าที่ด้วยอีเมล รหัสผ่าน และรหัสลงทะเบียน (ปิดรับสมัครได้โดยลบรหัสออกจากฐานข้อมูล) |

### Non-functional

| รหัส | ข้อกำหนด |
|---|---|
| NFR-1 | ใช้งานได้ทั้งมือถือและเดสก์ท็อป (responsive) |
| NFR-2 | เปิด Row Level Security ทุกตาราง ผู้ยื่นอ่านตาราง `requests` ตรง ๆ ไม่ได้ |
| NFR-3 | ไฟล์แนบเก็บแบบ private จำกัดชนิดและขนาด เจ้าหน้าที่เปิดผ่านลิงก์ชั่วคราวอายุ 2 นาที |
| NFR-4 | deploy ได้โดยไม่ต้อง build |
| NFR-5 | รองรับภาษาไทย/อังกฤษ สลับได้ทันที ค่าเริ่มต้นคือไทย |

## การพัฒนาต่อ

| ต้องการ | แก้ที่ |
|---|---|
| เปลี่ยนข้อความ หรือเพิ่มภาษา | `js/i18n.js` |
| เปลี่ยนหน้าตา | `css/styles.css` |
| แก้ฟอร์มยื่นคำร้อง / หน้าติดตาม / หน้าเจ้าหน้าที่ | `js/pages/request.js` / `track.js` / `admin.js` |
| เพิ่มหน้าใหม่ | สร้างไฟล์ใน `js/pages/` แล้วเพิ่มเส้นทางใน `routes` ของ `js/app.js` |

| จัดการประเภทเอกสาร | Supabase Table Editor → `request_types` |

## ข้อจำกัดที่ทราบ

- ยังไม่มีแจ้งเตือนทางอีเมล/LINE เมื่อสถานะเปลี่ยน
- ยังไม่มีการชำระเงินออนไลน์ (ค่าธรรมเนียมแสดงเป็นข้อมูลเท่านั้น)
- ยังไม่มีหน้าจัดการประเภทเอกสาร และการส่งออก CSV
- ยังไม่มี CAPTCHA หรือ rate limit บนฟอร์มสาธารณะ
- ยังไม่มีบทบาทเจ้าหน้าที่หลายระดับและ SLA
- การสมัครเจ้าหน้าที่ใช้รหัสลงทะเบียนร่วมกันหนึ่งรหัส ยังไม่มีขั้นตอนอนุมัติรายบุคคล ควรเปลี่ยนรหัสเมื่อมีคนลาออก และปิดรับสมัครเมื่อไม่ใช้

## Roadmap

1. แจ้งเตือนเมื่อสถานะเปลี่ยน (Supabase Edge Function + database webhook)
2. หน้าจัดการประเภทเอกสารและส่งออก CSV
3. ชำระเงินออนไลน์ (เช่น PromptPay QR) และใบเสร็จ
4. บทบาทเจ้าหน้าที่หลายระดับและ SLA
